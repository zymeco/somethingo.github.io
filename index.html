3D 도면 비교 · CAD · BIM

3D 파일 도면을 정밀 비교 · 분석하는 전용 툴

STEP 파일부터 IFC, OBJ까지 주요 포맷을 불러와 차이점을 빠르게 시각화합니다. 모델 버전이 바뀌어도 변경된 면, 추가된 부품, 치수 변동을 자동 감지합니다.

클라우드 · 온프레미스 모두 지원

기준 모델

STEP v1
피처 트리, 메타데이터, 형상 정보를 안전하게 로딩합니다.
IFC v2
BIM 객체, 좌표계, 속성을 통일된 스키마로 변환.

비교 모델

+24 수정된 면
차이 검출
솔리드/서피스 유무, 볼륨, 두께 변화를 히트맵으로 표시.
보고서
CSV · PDF로 결과 내보내고, 수정 요청 링크를 생성합니다.

무엇이 달라졌는지 한눈에

형상, 속성, 좌표계 변화를 정밀하게 비교합니다. 3D 뷰어 없이도 웹 브라우저에서 결과를 확인할 수 있습니다.

다중 포맷 지원

STEP, IGES, STL, OBJ, IFC, glTF 등 주요 엔지니어링 포맷을 로딩해 공통 형상 그래프로 정규화합니다.

형상 차이 히트맵

두께 변화, 오차 범위(±tol), 홀 추가/삭제를 색상 맵으로 표시해 문제가 되는 영역만 집중적으로 확인합니다.

속성 추적

재질, 공차, 파트 번호 등 메타데이터 변화를 필터링하고, 치수 테이블을 비교하여 BOM 변동을 잡아냅니다.

자동 보고서

변경 이력, 영향 범위, 검토자 메모를 포함한 PDF/CSV를 생성하고, Jira · Notion 링크 공유를 지원합니다.

워크플로우

1) 파일 업로드

기준/비교 모델을 업로드하거나 PLM, Git LFS, S3에서 바로 불러옵니다.

2) 정합 · 좌표계 보정

원점·좌표계를 맞춰서 회전, 스케일 차이를 자동 보정하고 공차 기준을 설정합니다.

3) 형상 & 속성 비교

볼륨, 면적, 피처 트리, 메타데이터를 모두 비교하여 변경된 요소만 추출합니다.

4) 시각화 & 공유

웹 뷰어에서 변경 영역을 하이라이트하고, 승인 워크플로우와 연결합니다.

기술 스택

엔진

Open Cascade 기반 커널로 형상을 정밀 비교, IFC는 IfcOpenShell 파이프라인으로 처리합니다.

실시간 뷰어

WebGPU/Three.js로 브라우저 기반 3D 뷰어를 제공하며, 모바일 터치 제스처를 지원합니다.

배포 옵션

사내 망 온프레미스, Docker Compose, Kubernetes 모두 지원. 데이터는 고객 인프라에만 저장됩니다.

API

REST · Webhook으로 비교 결과를 외부 시스템과 연동하고, SSO 및 RBAC로 접근 제어를 제공합니다.

시작하기

데모가 필요하거나 파일 비교 자동화가 필요하다면 아래 채널로 문의해주세요.

컨설팅

사용 중인 CAD/BIM 스택, 파일 규격, 품질 기준을 알려주시면 최적의 비교 파이프라인을 설계해드립니다.

파일 규격 테스트

STEP/IFC 샘플을 제공해주시면 호환성, 성능, 세그먼트 품질 리포트를 보내드립니다.

보안 옵션

VPN/IP 제한, 로깅, 데이터 파기 주기 등 보안 요구사항에 맞는 배포 구성을 안내드립니다.
